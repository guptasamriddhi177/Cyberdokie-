# Project Brief

## 1. Project overview
Cyberdokie is a compact touchscreen cyberdeck built around a Raspberry Pi 5 with 8GB RAM. The aim is to create a portable, customizable Linux computer for programming, learning, hardware experimentation, and everyday development tasks.

The Raspberry Pi 5 acts as the main computer. A touchscreen provides visual interaction, while a compact keyboard and optional pointing device provide text and cursor input. Additional peripherals may be connected through USB, GPIO, wireless connectivity, and the board's supported expansion interfaces.

## 2. Motivation
The project is intended to build practical skills in:
- Linux and operating-system configuration
- Python, C, and C++ programming
- Computer and peripheral integration
- GPIO and serial communication
- Touchscreen interface development
- Power and thermal planning
- PCB design and mechanical packaging

## 3. Project objectives
1. Configure a Raspberry Pi 5 (8GB) as the main computing platform.
2. Select and integrate a compatible touchscreen.
3. Provide reliable keyboard and pointing-device input.
4. Choose suitable storage and cooling.
5. Design a safe, maintainable power arrangement.
6. Develop a compact enclosure with accessible ports and ventilation.
7. Document the wiring, software setup, testing, and final configuration.

## 4. Scope
### Included
- Raspberry Pi setup and operating-system installation
- Display and input integration
- Storage and cooling selection
- Power-system planning
- Optional GPIO peripherals and STM32 expansion
- Enclosure planning and project documentation

### Not assumed
- A custom replacement motherboard for the Raspberry Pi
- A completed battery pack or power-management PCB
- A selected display model or verified pin-to-pin wiring
- Manufacturing-ready expansion PCB files

## 5. Success criteria
Cyberdokie will be considered functionally complete when:
- The Raspberry Pi boots reliably.
- The selected display shows the desktop at its intended resolution.
- Touch input works, if supported by the chosen display.
- Keyboard and pointing-device input work.
- Storage is detected and stable.
- The system remains within acceptable operating temperatures.
- Power remains stable under the intended workload.
- The enclosure allows safe airflow and access to required connectors.
- Build files and test results are documented.
