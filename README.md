### 1\. Project Overview

Cyberdokie is a custom-built touchscreen cyberdeck designed to function as a compact, portable computing platform. The project is based on the Raspberry Pi 5 with 8GB RAM, which serves as the main processing unit.

The primary objective is to build a powerful and customizable mini-computer that combines hardware engineering, software development, Linux-based computing, and embedded electronics.

I chose the Raspberry Pi 5 because it offers significantly more computing capabilities than a conventional microcontroller. Its 8GB RAM allows me to experiment with multitasking, programming environments, graphical interfaces, networking, and different software applications.

Another important aspect of Cyberdokie is the learning experience. I want to understand how individual hardware components communicate, how operating systems interact with hardware, and how a complete portable computing system can be designed from scratch.

### 6\. System Working

The Raspberry Pi 5 acts as the central computing unit.

* The Raspberry Pi boots from its microSD card or supported storage.

* The operating system initializes the hardware and software environment.

* The touchscreen displays the customized Cyberdokie interface.

* User inputs are processed through the touchscreen or keyboard.

* Applications execute using the Raspberry Pi's CPU and RAM.

* External hardware communicates through USB, GPIO, Bluetooth or other supported interfaces.

### 7\. Power and Thermal Management

Power management is an important part of this project because the Raspberry Pi 5 requires a stable power supply.

The proposed system includes:

* USB-C power input.

* A suitable 5V/5A power supply.

* Active cooling or a compatible heatsink.

* Proper ventilation inside the enclosure.

* A suitable battery-management solution if portable battery operation is added.

The battery system will need appropriate voltage regulation and protection rather than connecting a battery directly to the Raspberry Pi.

### 8\. PCB and Hardware Development

An important part of Cyberdokie is understanding how the Raspberry Pi can be integrated with custom electronic hardware.

I am exploring:

* Custom PCB development using KiCad.

* GPIO expansion and peripheral connections.

* Power distribution and regulation.

* Connector placement and cable management.

* Compact component layouts.

* Hardware integration within the cyberdeck enclosure.

The Raspberry Pi 5 itself is a premanufactured development board. Any custom PCB would serve as an expansion, interface or power-management board rather than replacing the main Raspberry Pi motherboard.

### 11\. Project Reflection

Cyberdokie is an opportunity for me to explore computing beyond traditional software development. I wanted to build something that combines hardware, programming, electronics and a practical user interface.

Choosing the Raspberry Pi 5 with 8GB RAM gives me a capable platform to experiment with Linux, programming, multitasking and hardware integration. I am particularly interested in understanding how software communicates with physical components and how different subsystems can work together inside one compact device.

I also want to explore PCB engineering and custom hardware development rather than depending entirely on commercially available modules. Although the Raspberry Pi 5 and its accessories can be relatively expensive, I believe the technical knowledge gained through this project will be valuable for my future robotics and embedded-system projects.

My ultimate goal is to develop Cyberdokie into a fully functional, customizable touchscreen cyberdeck that acts as my own portable computing and development workstation.
