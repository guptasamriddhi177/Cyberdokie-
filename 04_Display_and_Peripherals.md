## Typical HDMI touchscreen arrangement
- Raspberry Pi micro-HDMI output connects to the display's HDMI input using the correct cable or adapter.
- Touch data may use a separate USB connection, depending on the display model.
- Display power must follow the display manufacturer's specification.
- Some displays use DSI or other interfaces instead; do not assume all displays use HDMI and USB.

## Input devices
Potential input options:
- Compact USB keyboard
- Bluetooth keyboard
- USB mouse or trackpad
- Integrated keyboard/trackpad assembly

## Optional peripherals
- USB microphone
- Small speaker or USB audio device
- Camera module
- GPIO sensors
- External storage

Check power draw, connector compatibility, driver support, and physical clearance for each peripheral.
