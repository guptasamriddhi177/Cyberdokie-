# November 11, 2026: Made list of components

Today, I focused on the initial hardware planning and component
selection for CyberDokie, my touchscreen cyberdeck project. I started by
preparing a detailed list of the components that will be required to
build the complete system. This included exploring different processing
boards, touchscreen displays, power management modules, storage options,
connectivity modules, buttons, ports and other supporting hardware.

I also spent time understanding the purpose of each component and how it
would contribute to the overall functionality of the cyberdeck. Since
CyberDokie is intended to be a compact and portable computing device, I
considered factors such as component compatibility, size, power
consumption, performance and ease of integration.

Another important part of today's work was identifying the main hardware
requirements and separating essential components from optional
additions. I wanted to make sure that the selected components would work
together rather than choosing individual parts without considering the
complete system.

I also began thinking about the physical layout of the device,
especially the placement of the touchscreen, processing unit, power
system and external connectivity ports. The goal is to create a clean,
practical and professional design while keeping the device compact.
